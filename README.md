# Agentic RAG for Context-Aware Conversational Lead Qualification

Code, data and results for the paper "An Agentic Retrieval-Augmented Generation Framework for Context-Aware Conversational Lead Qualification" (ICMLDE 5.0, revised version under review). Every number in the revised manuscript is produced by the scripts in this repository.

The system is a LangGraph agent for a fictional SaaS product (AutoStream). It routes each user turn by intent, answers product questions by dense retrieval with history-aware query rewriting, and collects a lead (name, email, platform) in a sticky collection mode. The CRM write is structurally gated and can only run after all fields are present and confirmed by the user.

## Repository layout

- `kb/` fictional AutoStream knowledge base (17 Markdown documents, including a changelog with superseded prices and a blog post as realistic distractors)
- `lq/` system code
  - `agent.py` LangGraph graph of the proposed agent and its ablations
  - `retriever.py` dense retrieval with `bge-small-en-v1.5`
  - `extractor.py` rule-based extraction of lead fields
  - `baselines.py` LLM-only, full-context, naive RAG and LangGraph ReAct baselines
  - `prompts.py` every prompt, verbatim (agent, baselines, user simulator, judge, data generation)
  - `simulate.py` persona-based LLM user simulator
  - `evaluate.py` all experiments and metrics
  - `config.py` models, decoding and retrieval settings
- `data/qa.jsonl` 135 hand-written questions in 7 categories with reference answers, required key facts and gold source documents
- `data/intent_pool.csv` 400 intent messages (360 generated by Phi-4, 40 hand-written context-dependent items in `data/intent_context.jsonl`)
- `data/personas.jsonl` 200 held-out test personas (seed 7), `data/personas_dev.jsonl` and `data/personas_dev2.jsonl` the two development sets (seeds 42 and 2026)
- `data/intent_gold.csv` reference intent labels (384 messages on which the two label sets agree)
- `data/annotation/GUIDELINES.md` annotation guidelines for the intent labels and the answer-quality rubric, plus the agreement results
- `runs/` raw outputs and scored results of the reported experiments, plus `runs/env/` (pip freeze and configuration)
- `tests/test_offline.py` checks that need no GPU

## Models

All models are open-weight and served locally with vLLM 0.10.1.1 on one NVIDIA B200 MIG slice (45 GB).

| Role | Model | Settings |
|---|---|---|
| Agent and all baselines | Qwen/Qwen2.5-7B-Instruct | bf16, temperature 0, top-p 1, seed 42, max 384 output tokens |
| Test-data generation, user simulator, judge | microsoft/phi-4 | FP8 weights, simulator temperature 0.7 |
| Embeddings | BAAI/bge-small-en-v1.5 | top-k 4, 120-word chunks with 30-word overlap |

A different model family is used for simulation and judging to reduce self-preference bias.

## Main results

| System | QA correctness (%) | Hallucination (%) | Correct leads (%) | Unsupported / duplicate CRM writes |
|---|---|---|---|---|
| LLM only | 41.5 | 57.8 | n/a | n/a |
| Full knowledge base in the prompt | 95.6 | 3.0 | n/a | n/a |
| Naive RAG | 90.7 | 6.7 | n/a | n/a |
| LangGraph ReAct | 88.5 | 8.9 | 40.0 (batched), 66.3 (sequential) | 43 / 19 (batched), 21 / 21 (sequential) |
| Agentic RAG (proposed) | 91.1 | 5.9 | 93.7 (batched), 91.4 (sequential) | 0 / 0 |

QA results are on 135 questions, and lead results are on 200 held-out simulated customers (175 lead dialogues). See the paper for confidence intervals, ablations, field-level extraction scores and per-turn cost.

Intent classification is evaluated on the 384 of 400 messages whose two label sets agree (`data/intent_gold.csv`).

| Metric | Value |
|---|---|
| Accuracy | 91.7% [88.8, 94.3] |
| Macro-F1 | 0.81 |
| Accuracy on 40 context-dependent messages | 85.0% [72.5, 95.0] |
| Accuracy without the previous assistant turn | 91.7% (no measurable effect) |
| Agreement of the two intent label sets | Cohen's kappa 0.94 |
| Agreement of the two QA score sets (105 answers) | weighted kappa 0.96 (correctness), kappa 0.88 (hallucination) |
| LLM judge vs. agreed QA scores | weighted kappa 0.73 (correctness), kappa 0.69 (hallucination) |

Per-class scores and the confusion matrix are in `runs/intent_metrics.json` and `runs/intent_confusion.png`, and the agreement figures in `data/annotation/intent_agreement.json` and `data/annotation/qa_agreement.json`.

## Running

```bash
bash scripts/setup.sh       # virtual environment and CUDA 12.8 torch (needed for B200)
bash scripts/serve.sh       # start Phi-4 (port 8001) and Qwen2.5 (port 8000) with vLLM
bash scripts/run_all.sh 1   # data generation and all automatic experiments
# two annotators fill data/annotation/*_sheet_A.csv and *_sheet_B.csv independently
bash scripts/run_all.sh 2   # gold intent labels, intent metrics, inter-annotator agreement
python -m pytest tests/     # offline checks
```

Results are written to `runs/`.
